# Mid South Steel & Rebar — Fastener Counter

Static site (single `index.html`) listing Mid South's shelf fasteners and the full special-order line.
Orders and quote requests are emailed to sales@rebarandsteel.com through FormSubmit
(first submission triggers a one-time activation email to that inbox).

Hosted with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
